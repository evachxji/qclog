# 暖色Vlog 微信小程序 · 部署说明

## 项目结构

```
miniprogram/
├── app.js            # 小程序入口逻辑
├── app.json          # 全局配置（页面路由、导航栏颜色等）
├── app.wxss          # 全局样式
├── sitemap.json      # 搜索索引配置
├── img/
│   └── aig/          # 9 张照片资源
└── pages/
    └── index/
        ├── index.wxml   # 页面模板（对应 index.html 结构）
        ├── index.wxss   # 页面样式（px → rpx，适配所有屏幕）
        ├── index.js     # 页面逻辑（图片数据 + 点击全屏预览）
        └── index.json   # 页面级配置
```

## 上传发布步骤

### 第一步：准备微信小程序账号

1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册/登录小程序账号。
2. 记下你的 **AppID**（在「开发 → 开发管理 → 开发设置」中）。

### 第二步：安装微信开发者工具

前往官网下载安装：
👉 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 第三步：导入项目

1. 打开微信开发者工具，点击「+」新建项目。
2. **目录** 选择本文件夹：`d:\Document\trae\qclog\miniprogram`
3. **AppID** 填写你的真实 AppID（体验账号可选「测试号」）。
4. **后端服务** 选择「不使用云服务」。
5. 点击「确定」，即可在模拟器中看到效果。

### 第四步：真机预览（可选）

在开发者工具顶部菜单点击「预览」，用微信扫码即可在手机上查看。

### 第五步：上传发布

1. 在开发者工具顶部点击「上传」，填写版本号和备注。
2. 登录微信公众平台，进入「版本管理」。
3. 将上传的「开发版本」提交审核 → 审核通过后发布为「正式版本」。

## 功能说明

| 功能   | 说明                     |
| ---- | ---------------------- |
| 照片画廊 | 9 张生活照片以卡片形式展示         |
| 点击预览 | 点击任意卡片可全屏预览并左右滑动浏览全部图片 |
| 分享   | 支持转发给好友（右上角菜单）         |
| 懒加载  | 图片滚动到可视区域时才加载，节省流量     |

## 注意事项

- **图片大小**：微信小程序单包限制 **2MB**，建议将图片压缩后再上传。  
  推荐工具：[TinyPNG](https://tinypng.com/) 或 `ffmpeg`。
- **本地图片**：目前图片直接打包进小程序包，若图片较多建议上传至云存储（如微信云开发 / 腾讯云 COS），改用网络链接引用。
- **AppID**：正式发布必须填写真实 AppID，「测试号」仅供本地预览使用。
